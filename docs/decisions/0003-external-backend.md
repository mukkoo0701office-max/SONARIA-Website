# 0003: 申し込み・講師登録は外部バックエンド（Supabase）で処理する

- 日付: 2026-11-26
- 状態: **決定**（運営者の「申し込み・講師登録システム実装指示書 v1.0」と確認回答に基づく）
- 変更する決定: [0001](./0001-phase1-static-site.md) の「第2段階はさくらの契約プランを調べてから決める」

## 決定

| 項目 | 内容 |
|---|---|
| 画面 | これまでどおり Next.js の静的書き出し（GitHub Pages／さくら） |
| データベース・認証・ファイル保存 | **Supabase**（PostgreSQL・Auth・Storage） |
| サーバー側の処理 | Supabase Edge Functions（申し込みの検証・保存・料金計算・通知） |
| メール送信 | Resend（API キーは Edge Functions の環境変数だけに置く） |
| アクセス制御 | 全テーブルで行単位アクセス制御（RLS）。申し込みデータは管理人だけが読める |
| ファイル | 非公開バケット。アップロードは Edge Function が発行する署名付き URL だけ。種類と容量はバケット側でも制限 |

### 理由

- GitHub Pages・さくらの静的配信のままで、保存・認証・非公開ファイル・サーバー側検証をそろえられる
- 初期費用 0 円で始められる（無料プラン）
- 画面の配信先（GitHub Pages／さくら）を変えてもバックエンドはそのまま使える

## 運営者の確認回答（2026-11-26）

1. **講師登録の「レッスン料金」**: 管理用の**非公開項目**として受け取る。フォームに「公開されません」と明記する。検索結果・プロフィール・検索条件には一切使わない
   - これにより VISION §4／講師 UI 仕様 §1 の「料金の入力欄も作らない」を、「**公開・検索・表示はしない。管理用の非公開入力のみ可**」に改める
2. **レッスン料金**: 指示書の数字を使う（体験 1,000 円／単発 60 分 6,000 円／集中プラン 月額 11,000 円・合計 2 時間 30 分／出張 2 時間 10,000 円）。旧サイトの料金とは異なる
3. **メール**: 送信元ドメインの認証ができるまで、**管理人への通知だけ**を送る。申込者への受付確認メールは未接続と明示し、完了画面に受付番号と内容を表示する

## 無料プランの制約と対策

| 制約 | 対策 |
|---|---|
| Supabase 無料プランは 1 週間使われないと停止する | GitHub Actions で週 2 回アクセスして停止を防ぐ（`keepalive.yml`） |
| Supabase 無料プランは自動バックアップなし | 管理画面から CSV を書き出せるようにする。重要データは定期的に書き出す |
| Supabase のファイル保存は合計 1 GB・1 ファイル 50 MB | 楽譜は 1 ファイル 20 MB まで。録音の大容量音源は共有 URL（Google ドライブ等）で受け付ける |
| Resend 無料プランは 1 日 100 通・月 3,000 通。申込者への送信には送信元ドメインの認証が必要 | 当面は管理人通知のみ。ドメインを用意したら環境変数で申込者への送信を有効にする |
