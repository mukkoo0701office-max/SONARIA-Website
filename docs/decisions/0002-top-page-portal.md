# 0002: トップページを画像中心のポータル構成にする

- 日付: 2026-11-26
- 状態: **決定**（運営者の「トップページ改修指示書 v1.0」に基づく）
- 関連: [0001-phase1-static-site.md](./0001-phase1-static-site.md)、[SONARIA_TEACHER_DIRECTORY_UI_SPEC_v1.0.md](../SONARIA_TEACHER_DIRECTORY_UI_SPEC_v1.0.md)

## 決定

| 項目 | 内容 |
|---|---|
| ヘッダー | 固定。ホーム／楽譜を探す／ボウイング・運指付け／レッスン／レコーディング依頼／演奏依頼／向山弦楽コミュニティ／管理人について。PC は横並び、スマホはハンバーガー |
| メインビジュアル | 8 枚のカルーセル。6 秒で自動切替、操作後 12 秒・マウスオーバー中・フォーカス中は停止、一時停止ボタンあり、動きを減らす設定では自動再生しない |
| 中段 | 講師簡易検索（楽器・都道府県・対面／オンライン・出張対応）。詳しい条件は講師検索ページ |
| ピックアップ | SONARIA の有料サービス 4 件の横スライドカード。`src/data/services.ts` で管理。料金は未設定のあいだ表示しない |
| フッター | ロゴ、サイト内リンク、お問い合わせ、プライバシーポリシー、SNS（URL 未設定はリンクにしない）、コピーライト |
| 仮画像 | `public/images/placeholders/`（抽象図形のみ）。差し替えは `src/data/images.ts` の一覧だけを書き換える |

## 既存仕様との調整

- **講師のデモデータ**: 指示書は「仮データで動作確認」、講師 UI 仕様 §7 は「本物の登録が出るまで本番にサンプル講師を出さない」。→ 架空の講師は**プレビュー（GitHub Pages）のビルドだけ**に含め、本番ビルドには含めない。CI で本番出力に含まれていないことを確認する
- **講師の性別・対象の絞り込み**: 指示書には無いが、承認済みの講師 UI 仕様 §3 に沿って講師検索ページに置く（トップの簡易検索には置かない）
- **有料サービスと無料講師ディレクトリの区別**: ピックアップに「SONARIA の有料サービスで、講師検索の掲載順とは関係ない」と明記する（講師ディレクトリの非優遇の原則を守るため）
- **講師の簡易プロフィール URL**: 静的書き出しのため `/teachers/profile/?id=...`。個別 URL（`/teachers/{id}/`）は講師データの公開方式が決まってから

## 要確認

- ヘッダーに「講師を探す」が無い（トップの中段とフッターから入れる）。無料講師ディレクトリはサイトの主要機能のため、ヘッダーに入れるか
- 「向山弦楽コミュニティ」の英語表記（仮: Mukoyama Strings Community）
- SNS の正式 URL、各 SNS の公式アイコン素材
