# SONARIA — 事業・Webサイト構想／決定事項
更新: 2026-11-23
状態: 構想整理版。確定事項と検討事項を区別する。

## 1. ブランド（採用方針）
- 名称: **SONARIA（ソナリア）**。
- ネーミングストーリー: **SONG × ARIA**。英語の正式な合成語という意味ではなくブランド上の由来。
- ロゴ: ユーザーが最終承認した画像を正本とする。ネイビー×ゴールド、白背景、流麗なS、SONARIAのセリフ体ロゴ、金色の弧と星、下部に SONG／ARIA。中央には**弦楽器を包み込む「＆」状の金色リボン**を配置。画像の当該部分は寸分違わず維持する意向。画像そのものは別途原本をアップロードする必要がある。再生成した類似画像を正本とみなさない。
- **要確認:** SONARIAの商標・既存事業名・ドメインのクリアランスは未完了。名称採用方針と法的使用可能性は別。

## 2. サイトの位置づけ（決定）
- クラシック音楽を中心とする、独立した中立的な音楽プラットフォーム。
- 管理者個人の宣伝サイトにしない。管理人プロフィールを別ページに設け、必要な法定表示以外では個人名・個人の音楽性を前面に出さない。
- 楽曲、楽譜、演奏者・講師、コミュニティ、音楽教育の利便性と品質を優先する。
- 日本語・英語対応を想定。

## 3. 主要機能（構想）
1. ホーム／作品検索・発見。
2. クラシック楽譜の無料検索・閲覧・ダウンロード用ライブラリ。
3. 運指・運弓付き楽譜の有料版、編曲・録音・レッスン等のサービス。
4. **完全無料**の音楽講師検索・生徒との問い合わせ仲介。
5. 弦楽コミュニティ、演奏会・イベント情報。
6. 教材・リソース、問い合わせ、管理人プロフィール。
7. 将来的に寄付、広告・アフィリエイト等の任意収益化。

## 4. 無料音楽講師ディレクトリ（重要な決定）
- 講師登録・掲載・生徒紹介・問い合わせは**完全無料**。月額料金、紹介料、仲介手数料、有料優先掲載なし。
- 対象は音楽大学の在学生または卒業生。本人・経歴確認と掲載審査を設ける。
- 楽器カテゴリは**ピアノ、木管、弦楽器、金管**の4種。
  - 木管: フルート、オーボエ、クラリネット、ファゴット。
  - 弦: ヴァイオリン、ヴィオラ、チェロ、コントラバス。
  - 金管: トランペット、ホルン、トロンボーン、チューバ。
  - 複数楽器の指導登録を許容。
- 地域: 都道府県＋最寄り駅、必要に応じて複数駅。検索・絞り込み可能。
- レッスン形態: 自宅／自身のスタジオ、貸スタジオへの出張、生徒宅出張、オンライン等。
- 出張範囲: **「最寄り駅から公共交通機関で約○分圏内」**など、起点・移動手段を明示して登録。
- プロフィール: 本人許諾済み写真、学校・経歴、指導方針、対象生徒、演奏動画、SNS・Webサイト、プライバシー保護された問い合わせフォーム。
- 年齢の掲載は任意で**年代のみ**。生年月日を公開せず、年齢による優先順位付けをしない。
- **レッスン料金・価格帯はプロフィールや検索結果に一切表示しない。料金検索・料金フィルタも設けない。** 音楽性、指導方針、相性で選ぶ。金額は講師と生徒が直接相談し、契約前に総額を確認。
- 架空講師・架空評価は掲載しない。サイト管理者の優先順位付けなし。
- 外部演奏家・浄書者・編曲者等の協力者登録、仕事の紹介への任意オプトインを検討。依頼・報酬は人間が承認し、義務は課さない。

## 5. 楽譜ライブラリ／移行（構想・作業方針）
- 既存Jimdoサイト https://www.mukkoo0701music.jp/ のPDF・URLを棚卸し。原本保存、再試行付き取得、SHA-256重複排除。
- 最初は**20〜30 PDFの試験移行**を実施し、分類・権利・SEOを確認してから拡大。
- メタデータ: 作曲者、作品、作品番号、楽章、編成、版、パート、校訂者、出版社、出版年、出典、著作権・再配布可否。
- **閲覧可能＝再配布可能ではない**。既存PDFもIMSLP由来PDFも、権利・利用規約・地域差を確認する。
- 版の品質スコア案: 信頼性35、校訂者／出版社20、視認性20、実用性15、書誌情報10。AI候補と人間が確認した「推奨版」を区別し、個人名を冠した推奨表記は避ける。
- 作曲家肖像等の画像はライセンス・出典・クレジットを管理。
- SEO: 旧URL→新URL対応表、可能な301リダイレクト、canonical、hreflang、サイトマップ、Search Console、アクセス解析、移行後の404監視。
- 移行先ホスティング候補: さくらインターネット。ドメイン維持を想定。
- 弦楽コミュニティ既存サイト https://mukstrings.mints.ne.jp/ のコードは、提供・利用許可・ライセンス確認後に活用。
