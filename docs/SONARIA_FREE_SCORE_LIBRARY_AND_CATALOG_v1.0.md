# SONARIA 無料楽譜ライブラリ・全作品一覧 UI仕様 v1.0

Status: **採用決定（2026-11-24）**。この文書は仕様であり、HTML実装・公開はまだ行っていない。

## 大柱1：二つの楽譜探索体験
### 中柱1.1：既存の楽譜検索UIを中心機能として維持
- 既存の承認済み `prototypes/score-search-ui-v1.html` と `docs/SONARIA_UI_DESIGN_SYSTEM_v1.0.md` を基準にする。既存の楽器・演奏人数・編成・形式・作曲家等の検索体験を損なわない。
- 検索ページ内で作品を探す体験だけでも完結できるようにする。
### 中柱1.2：「すべての楽譜を見る」全作品一覧
- 検索UIから明瞭なCTA「すべての楽譜を見る」で、サイトで公開中の作品を一覧表示する専用画面へ遷移。
- 一覧はコンパクトな行表示を基本とし、カード表示にも切り替え可能。作曲家名、作品名、作品番号、編成・楽器、必要に応じて公開譜面の種類を表示。
- 一覧から各作品詳細ページへ移動できる。検索と一覧は**同一の作品データベース**を参照し、別々の登録・管理をしない。
- 30〜50件程度ずつページネーション／段階的読込。全件を一括DOM描画しない。URLでページ番号・ソート・条件を再現可能にする。
- ソート：作曲家、作品名、作品番号（番号の種類を考慮）、新着。作曲家別・楽器別・編成別のブラウズも提供。
- 実際の検索結果数と、ライブラリ総作品数を混同しない。

## 大柱2：「無料楽譜ライブラリ」を視覚的に強調
### 中柱2.1：ヒーローバナー
- SONARIA MUSIC LIBRARY / **無料楽譜ライブラリ** / Free Sheet Music Library を視認性高く表示。
- 本・楽譜のアイコン等を用い、**無料の楽譜を探せる場所**であることが一目で分かるようにする。
- 推奨スタイル：ネイビー `#182B45` 背景、シャンパンゴールド `#B79656` アクセント、明るいテキスト、オフホワイト `#FAF9F6` ページ背景。既存デザインシステムを尊重。
- ヒーロー直下に検索入力と、明確な二導線「条件から探す」「すべての楽譜を見る」。モバイルで無理なく見える配置。
### 中柱2.2：公開作品数カウンター
- 「公開中の無料楽譜 **全○曲**」を大きく、誇らしく表示する。実際のデータから自動算出し、固定の仮数値を本番に使わない。
- カウントの単位を明示：**公開作品数**を基本とする。PDFファイル数、版数、パート数、楽章数と混同しない。必要なら「公開作品 ○件／ダウンロード可能な譜面 ○点」を別表示。
- 同一作品の重複版・パート譜は作品数として重複計上しない。非公開・権利未確認・削除済みを除外。公開権利の確認済み作品のみ含める。
- サンプルUIで示した「1,284曲」は仮数値であり実績ではない。

## 大柱3：作品詳細と発見機能
### 中柱3.1：作品詳細ページ
- 作品情報、作曲家、作品番号、編成、楽章、版・パート、権利確認済みのPDF、必要に応じてプレビュー、関連作品へ導く。
- 検索結果・全件一覧・作曲家別ページから同じ作品の正規URLへ遷移。
### 中柱3.2：追加ブラウズ
- 新着楽譜：公開日時に基づく。
- 人気の楽譜：閲覧数／ダウンロード数など実測値がある場合のみ。未計測時は「人気」と表示しない。
- 作曲家から探す、楽器から探す、編成から探す。
- ランダムな1曲：公開・権利確認済み作品から選択。
- これらは基本機能（検索＋全件一覧＋作品詳細）を優先し、段階的に導入してよい。

## 大柱4：ナビゲーションとUI品質
- トップ → 無料楽譜ライブラリ → 【検索エンジン／全楽譜一覧】 → 作品詳細 → PDF の情報構造。
- 検索画面から一覧、一覧から検索へ往復可能。検索条件と閲覧位置をできる限り保持。
- JA/EN対応。見出し・操作ラベル・件数の単位を翻訳し、明示的な言語設定を優先。
- 一覧には空状態、読み込み状態、エラー、権利確認中の非公開処理、アクセシブルなキーボード操作を用意。
- SEO：正規作品URL、ページ送り可能なクロール経路、作品の重複URL管理、適切なタイトルと内部リンク。
- PDFを公開する前に、原典／版／編曲ごとに公開・再配布権限を確認。

## 受入条件
1. ライブラリのバナーを見て無料楽譜を扱うサイトだと直感的に分かる。
2. 実数ベースの「全○曲」が大きく表示される（仮数値は本番で不可）。
3. 採用済みの検索UIは機能・視覚の両面で維持。
4. 「すべての楽譜を見る」から公開作品をページ送りで最後まで閲覧できる。
5. 行一覧／カード切替、基本ソート、作品詳細への遷移が機能。
6. 検索と全件一覧でデータの食い違いがない。
7. スマホで高速・明快に操作できる。
8. 既存サイト移行時は権利、URLリダイレクト、データ重複を検証する。
