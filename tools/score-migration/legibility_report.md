# 楽譜 PDF の視認性検査（2026-11-27）

対象: 掲載中の 492 ファイル（156 作品）。検査記録は `ci/score-legibility` ブランチ（legibility.json・拡大画像）。

## 方法
1. 全ファイルから最大 8 ページを抜き出し、埋め込み画像の解像度・くっきり度（エッジの分散）・濃淡の差・黒い画素の割合を測定（`legibility.py`）
2. 次のいずれかに当たるファイルを「疑わしい」とした: 解像度 150ppi 未満／濃淡の差 170 未満／くっきり度 2500 未満／黒い画素が 2% 未満または 30% 超
3. 疑わしいファイルの、いちばん悪いページの中央部分を 150dpi で拡大して目視（`legibility_crops.py`）

## 結果
| 区分 | ファイル数 |
|---|---|
| 浄書譜（文字・図形の PDF。拡大してもつぶれない） | 111 |
| スキャン譜 | 381 |
| 数値で疑わしい | 46 |
| 目視で読めない（間引き対象） | **0** |

- 「72ppi」と出たファイル（バッハ無伴奏、ベートーヴェンのヴァイオリン・ソナタ全曲など）は、PDF 上の解像度表記が 72 なだけで、
  ページの画像自体は大きく、音符・臨時記号・スラーは鮮明
- 濃淡の差が小さいもの（コレッリ《クリスマス協奏曲》、クライスラー《プルチネッラ》など）は、紙の地色が残ったスキャン。音符は読める
- セヴシック Op.2 は解像度が低く拡大するとややぼやけるが、音符・スタッカート・テヌートは判別できる（印刷すると小さめ）
- 判読できない楽譜（自筆譜のファクシミリ、透かしだけのもの）は、移行時の検査で「中身を確認できない」としてすでに保留にしている
